# Code Of Conduct

This project should stay practical, respectful, and safe for contributors and users.

## Expected Behavior

- Be direct and constructive.
- Keep discussion focused on the code, docs, and user safety.
- Respect privacy. Do not post real cookies, account data, private messages, screenshots, or profile details from Nanny Lane.
- Assume good faith while still asking for evidence when behavior or claims affect security, side effects, or correctness.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing someone else's private account data.
- Encouraging use against accounts, browsers, or machines the user does not control.
- Changes that hide or weaken message-sending guardrails without clear review.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Security-sensitive issues should be handled privately first, following [SECURITY.md](SECURITY.md).
